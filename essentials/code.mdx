description: 'AppJet is compatible with any platform'

---

AppJet deployment uses Dockerfile, you can deploy your app everywhere Dockerfile deployment is authorized.

Checkout https://qoddi.com if you are looking for a battle ready hosting platform compatible with Docker.

You can also ask the agent to prepare your code to be deployed on several platforms including vercel, netlify (for JS assets), Heroku etc...
