A deployment URL is automatically created when you open a repository. Additionally, an Edge CDN enpoint (provided by Cloudflare) is automatically created for the appjet branch.

The appjet branch is used to connect your custom domains, custom domains cannot be connected to other branches.

## Dev and Edge endpoints

Dev endpoints are created for every branch you connect to AppJet. Those endpoints doesnt have any cache policy and are not intended to use in production.

The Edge endpoint is also created for your appjet branch and can be used to connect a custom domain.
