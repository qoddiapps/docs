To create a complete project we suggest that you start by creating a brand new repository:

![Create a new repo on AppJet](/createrepo.png)

Once your repository is created you can describe your project (this will be your first prompt) and choose a design inside a curated list.

For this example we will use the standard design and ask the agent to create a CRM app for startup founders :

![Second step creating a project with AppJet](/secondstep.png)

The agent immediately goes to work and create all appropriate files, you can see messages during his work detailling the process:

![Coding the app with AppJet](/working1.png)

and informs you of what is built as soon as the work is finished. The code is also available on the right side of the screen:

![Coding the app with AppJet](/working2.png)

The agent will ask if you want to deploy the app to see it in action, say yes and once the build is finished, open your application from the Settings>Overview tab to see the result:

![The result](/result.png)

Once it's done you can add more functions, setup persistent storage with a local disk or Supabase, add your custom domain etc...

You can see the result of this prompt here: https://yv76ej2t1t.dev.onappjet.com/
